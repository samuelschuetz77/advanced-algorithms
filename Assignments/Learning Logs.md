# Learning Logs

- **Type:** Canvas page (course policy / instructions, not an assignment)

Referenced by every "Learning Log N" assignment as `[[Learning Logs]]` — the
full instructions and point rubric behind the "at least 50 combined points"
requirement.

## Instructions (from Canvas)

Track key questions, problems, and insights from current or past
lectures/assigned reading/assignments. You need at least 50 points total to
get full credit for the learning log assignment each class period.

Always use your non-AI-enabled Classwork Profile (see [[ClassworkProfile]])
when writing or editing code or learning logs in this class.

## Per-field point values

Each log entry can earn points per field, summed toward the 50-point total:

| Field | Points |
|---|---|
| Question/Problem — identify an important question or key problem to solve | 3 |
| When Identified — day and time | 1 |
| Importance (1-5 scale, 5 = very important) | 2 |
| How to Learn — planned/taken strategy (reading, videos, questions, exercises, etc.) | 2 |
| Insight/Answer — key insight, answer, or progress made | 3 |
| Hours Spent Learning | 1 |
| Minutes Spent Documenting | 1 |
| Confidence (1-5 scale, 5 = fully satisfied, don't expect a better answer) | 1 |

**Max per fully-filled-out entry: 14 points.** So ~4 solid entries (all 8
fields filled in) clears the 50-point threshold for a given log submission.
